# Time Converter
Lightweight desktop utility for converting and comparing time units (GUI available).

## Features
* **Time Conversion:** Converts time values between seconds, minutes, hours, days, weeks, months and years.
* **Time Comparison:** Compares two time intervals and displays the relation in between (`>`, `<`, or `=`).

**User Notification:** potential inaccuracies upon calculating long time data **(month == 30 days, year == 365 days)**.
