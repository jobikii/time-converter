# Time Converter
A lightweight desktop utility with a graphical user interface for converting and comparing time units.

## Features
* **Time Conversion:** Converts time values between seconds, minutes, hours, days, weeks, months and years.
* **Time Comparison:** Compares two time intervals and displays the relationship (`>`, `<`, or `=`).

**User Notification:** potential inaccuracies when calculating months **(month == 30 days)**.
